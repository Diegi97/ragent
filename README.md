# RAGent

RAGent is a research project for evaluating and training language models on agentic search over data sources and knowledge bases. It provides pipelines for creating grounded search tasks, retrieval infrastructure, and an environment where models can iteratively search, inspect evidence, and answer complex questions.

## Data pipelines

[`data_pipelines/`](data_pipelines/) contains Prefect pipelines for generating and evaluating agentic-search data, with Phoenix tracing and JSONL outputs. Deep-search task generation is the project's primary and most important pipeline; the other pipelines are secondary experiments built out of interest.

- **Deep-search task generation** — creates grounded, multi-document tasks for evaluating and training search agents.
- **Retrieval-query generation** — creates realistic queries written by search agents—not human search queries—then identifies positive chunks and mines hard negatives.
- **Retrieval evaluation** — measures dense, BM25, hybrid, and reranked retrieval at both chunk and document level.

The deep-search pipeline samples entities from a data source, gathers the available facts and supporting documents for each entity, and then uses a [Pi](https://github.com/earendil-works/pi) agent to create a validated question-rubric pair.

See the [data pipelines README](data_pipelines/README.md) for setup, architecture, and pipeline commands.

## Deep-search environment

[`environments/ragent_deep_search/`](environments/ragent_deep_search/) is a [Verifiers](https://github.com/PrimeIntellect-ai/verifiers) v1 environment for evaluating and training models on iterative, grounded search. Agents can search the configured knowledge base, read complete documents, scan corpus text, and answer questions graded by per-example rubrics. It supports BM25, dense, hybrid, and reranked hybrid retrieval.

The environment is also available on the [Prime Intellect Environment Hub](https://app.primeintellect.ai/dashboard/environments/diegi97/ragent-deep-search). See its [README](environments/ragent_deep_search/README.md) for setup, configuration, and evaluation details.

## Retrieval architecture

RAGent uses LanceDB as its local retrieval backend. Every indexed data source has a searchable chunk table and a document table: agents retrieve compact chunks with dense search, BM25, or hybrid search, optionally apply CrossEncoder reranking, and fetch complete documents only when needed. Dense retrieval uses [Harrier 0.6B](https://huggingface.co/microsoft/harrier-oss-v1-0.6b) by default, while reranked retrieval uses [mxbai-rerank-base-v2](https://huggingface.co/mixedbread-ai/mxbai-rerank-base-v2). The agent interface exposes `search`, `read`, and `text_scan` tools over this backend.

Indexes are built from the [`diegi97/ragent_data_sources`](https://huggingface.co/datasets/diegi97/ragent_data_sources) dataset with [`ragent_core/scripts/build_lancedb_indexes.py`](ragent_core/scripts/build_lancedb_indexes.py). The available sources include:

- GitLab Handbook, PostHog documentation, DevDocs.io, and OWASP Cheat Sheets
- IETF RFCs, Rust RFCs, and Python Enhancement Proposals
- BrowseComp Plus and filtered Common Pile news and USPTO corpora

PersonaHub can be indexed separately as a future diversity pool for synthetic-data generation, but its pipeline integration is still a work in progress and it is not currently used. See the [`ragent_core` README](ragent_core/README.md) for indexing and data-source management commands.

## Model services

[`model_services/`](model_services/) provides BentoML services for Harrier embeddings and mxbai reranking. They allow concurrent pipeline runs and environment rollouts to share independently scalable model deployments. See the [model services README](model_services/README.md) for setup and configuration.

## `ragent_core`

[`ragent_core/`](ragent_core/) is the shared Python package containing data-source loaders, LanceDB retrievers, agent tools, judges, types, utilities, and the repository's index-management scripts; its [README](ragent_core/README.md) documents setup and operational commands.

### Rubric dataset provenance

The current `ragent-rubrics` dataset was generated with:

- **Retrieval embeddings:** [Harrier 0.6B](https://huggingface.co/microsoft/harrier-oss-v1-0.6b)
- **Retrieval reranking:** [mxbai-rerank-base-v2](https://huggingface.co/mixedbread-ai/mxbai-rerank-base-v2)
- **Fact extraction:** DeepSeek V4 Flash via Fireworks (`accounts/fireworks/models/deepseek-v4-flash`)
- **Question-rubric generation:** GLM-5.2 via Fireworks (`accounts/fireworks/models/glm-5p2`), using the [Pi](https://github.com/earendil-works/pi) agent harness

## Setup

Python 3.12 or newer and [`uv`](https://docs.astral.sh/uv/) are required. Each module is an independent project with its own environment and setup instructions; follow the README in the module you want to use.

## Development checks

Repository-wide formatting and linting use the Ruff version pinned by the root `uv.lock`:

```bash
uv sync
uv run ruff check .
uv run ruff format --check .
```

Apply safe lint fixes and formatting with:

```bash
uv run ruff check --fix .
uv run ruff format .
```
